# Ғафурҷон Уайдулоев — Портфолио

Портфолиои касбии Ғафурҷон Уайдулоев: барномасоз, муҳандиси сохтмон ва созандаи TOJ POS, TOJ ERP, DataMatrixPro ва MatrixPrint.

## Технологияҳо

HTML, CSS, JavaScript, Node.js, SQL, MySQL, PHP, GitHub, Render ва серверҳо.

## Иҷрои маҳаллӣ

```bash
npm install
npm run dev
```

## Ҷойгиркунӣ дар Render

Лоиҳа дорои `render.yaml` аст. Render онро бо Node.js 22 месозад ва тавассути `npm run start` оғоз мекунад.
